Implementation rules (RESEARCH Security Domain, V5 input validation; file bytes are untrusted):
- All offsets are `u64`. Convert to `usize` only after clamping to `data.len()`; use `saturating_add`/`checked_add`, never `start + 128` unchecked. No `unwrap()`/indexing that can panic on any `u64` input.
- `row_end`: window = `[start, min(start.saturating_add(BYTES_PER_ROW), len))`; if `memchr`-style search (use `iter().position(|&b| b == b'\n')`, no new crate) finds `\n` at index k, return `start + k + 1`; else window end.
- `visible_rows`: loop `count` times from `clamp`ed `top` (if `top >= len` return empty), push `start..row_end(start)`, stop at EOF.
- `prev_row_start(data, top)`: if `top == 0` return 0; `ws = top.saturating_sub(BYTES_PER_ROW)`; search `data[ws .. top-1]` (excludes the byte just before `top`, which may be the previous row's `\n`) for the LAST `\n` at index k -> return `ws + k + 1`, else return `ws`. Document in a doc comment that Phase 1 rows are byte windows and this is not an exact inverse for lines longer than 128 bytes; Phase 2 replaces it with the line index (CONTEXT: no sparse line index yet).
- `scroll_rows`: positive delta applies `row_end` delta times (stop at the last row start, never reaching `len`); negative applies `prev_row_start`. Result passed through `clamp_offset`.
- `display_text`: strip one trailing `\n` and a preceding `\r`; then iterate `bytes.utf8_chunks()` (stable std): for each valid char, push it unless `char::is_control()` (push `NON_PRINTABLE` instead); for each invalid byte push `NON_PRINTABLE`. Stop after `MAX_ROW_CHARS` chars (UI-SPEC: 4096-char cap; RESEARCH: layout DoS mitigation).
- `thumb_geometry`: if `len == 0` return `(0.0, track_h)`; `h = max(MIN_THUMB, track_h * visible_bytes as f64 / len as f64)` clamped to `track_h`; `y = (top as f64 / len as f64) * (track_h - h)` clamped to `[0, track_h - h]`. Do the ratio in f64 (f32 loses precision above 2^24, RESEARCH Pattern 3).
- `offset_for_thumb`: `frac = clamp(thumb_y / (track_h - thumb_h), 0, 1)` in f64; `off = (frac * (len - 1) as f64).round() as u64`; return `clamp_offset(off, len)`; if `track_h <= thumb_h` return 0.
- `format_size`: base 1024 with labels B, KB, MB, GB, TB (UI-SPEC: "GB" label, not "GiB"); bytes < 1024 print as integer `"{n} B"`, else one decimal.
- snap.rs: `snap(v, ppp) = (v * ppp).round() / ppp`; `row_y(top, i, row_h, ppp) = snap(top + i as f32 * row_h, ppp)` (RESEARCH Pattern 7: keep stride constant, snap each row). Guard `ppp <= 0.0` by returning `v` unchanged.

No egui types in these two files: they must stay pure so they test without a window.
