`src/bench.rs`:
```rust
pub struct StartupClock { t0: std::time::Instant, bench: bool, frames: u32, startup_ms: Option<u64> }
impl StartupClock {
    pub fn new(t0: std::time::Instant, bench: bool) -> Self;
    pub fn on_frame(&mut self, ctx: &egui::Context);   // call at the top of every App::ui
    pub fn startup_ms(&self) -> Option<u64>;
}
pub fn format_lines(backend: &str, startup_ms: u64, first_frame_unix_us: u128) -> String;
```
`on_frame` (RESEARCH Pattern 4): frames += 1; on frame 1 call `ctx.request_repaint()` exactly once; on frame 2 (frame 1 is presented by then; eframe shows the window after the first render) set `startup_ms = t0.elapsed().as_millis()`, compute wall clock `SystemTime::now().duration_since(UNIX_EPOCH)` in micros, and if `bench` write `format_lines(BACKEND, ..)` to `std::io::stdout().lock()` and `flush()`, ignoring write errors. After frame 2 it never requests repaints (idle purity, PERF-02).

**`src/view/mod.rs`** — keep `pub mod rows; pub mod snap;` and add:
```rust
pub struct ViewState { pub top: u64, scroll_accum: f32, visible_rows: usize }
impl ViewState { pub fn new() -> Self; pub fn top(&self) -> u64;
    pub fn show(&mut self, ui: &mut egui::Ui, data: &[u8]) -> egui::Response; }
```
`show` (RESEARCH Pattern 3; UI-SPEC "Virtualized view"):
1. `let (rect, response) = ui.allocate_exact_size(ui.available_size(), egui::Sense::click_and_drag());` fill rect with DOMINANT via painter.
2. Reserve a 12pt-wide scrollbar strip on the right; text area = rest.
3. `let ppp = ui.pixels_per_point();` read every frame, never cached (RESEARCH Pattern 7: ScaleFactorChanged is handled by egui-winit; the app must not cache pixel values).
4. `n = rows::rows_for_height(text_rect.height())`; `rows::visible_rows(data, self.top, n)`. For each row i: `y = snap::row_y(text_rect.top(), i, rows::ROW_HEIGHT, ppp)`; gutter `rows::format_gutter(range.start)` in MUTED at `x = text_rect.left() + 16.0` (16pt left inset); text `rows::display_text(&data[start..end])` in TEXT at `x = gutter_x + gutter_galley.size().x + 16.0` (snap x with `snap::snap`). Lay out with `painter.layout_no_wrap(text, FontId::monospace(14.0), color)` and draw with `painter.galley(pos, galley, color)`. Slice with `usize::try_from` on ranges already clamped by `visible_rows`.
5. Input, only when the pointer is over `rect` or the view has focus: `ui.input(|i| i.smooth_scroll_delta.y)` added to `scroll_accum`; whole rows = `(scroll_accum / ROW_HEIGHT).trunc()` -> `rows::scroll_rows(data, self.top, -rows)`, keep remainder. Keys: ArrowDown/ArrowUp = ±1 row, PageDown/PageUp = ±(n-2).max(1) rows, Home = 0, End = `rows::clamp_offset(len.saturating_sub((n as u64) * rows::BYTES_PER_ROW), len)`.
6. Scrollbar: track fill SECONDARY; `(y, h) = rows::thumb_geometry(self.top, len, n as u64 * BYTES_PER_ROW, track.height())`; thumb fill MUTED (min 24pt). `ui.interact(track, id.with("sb"), Sense::click_and_drag())`; on drag or click set `self.top = rows::offset_for_thumb(pointer_y - track.top() - h/2, track.height(), h, len)`.
7. Never call `request_repaint` here (RESEARCH Pattern 5). Scrolling repaints come from input events only.
