```rust
pub fn parse_size(s: &str) -> Result<u64, String>;           // suffixes: none, KiB, MiB, GiB, TiB (1024^n), KB, MB, GB (1000^n); 0 rejected
pub fn create(path: &Path, len: u64, force: bool) -> std::io::Result<()>;

pub fn run(args: lexopt::Parser) -> ExitCode;                 // `cargo xtask sparse --size 20GiB [--force] <path>`
```
`create` (RESEARCH "Sparse file helper"; per CONTEXT "set_len + a few written markers"):
1. If `path` exists and `!force` -> `Err(AlreadyExists)` (Security V12: never clobber non-test files). Open with `OpenOptions::new().read(true).write(true).create(true).truncate(true)`.
2. Windows: BEFORE `set_len`, call `DeviceIoControl(handle, FSCTL_SET_SPARSE, null, 0, null_mut, 0, &mut ret, null_mut)` (handle = `f.as_raw_handle() as _`); on failure return the OS error with a message noting that the volume must be NTFS/ReFS (exFAT/FAT32 unsupported). Without this flag NTFS zero-fills the gap when the end marker is written (RESEARCH Pitfall 1). If the windows-sys path names fail to compile (A1), fall back to `std::process::Command::new("fsutil").args(["sparse", "setflag", path])` and record that in the SUMMARY.
3. `f.set_len(len)`; then write ASCII text at offset 0 = `WHIM-START\n` followed by 40 lines `line NN: whim sparse test file\n` (so the first page shows text, RESEARCH note), `WHIM-MIDDLE\n` at `len / 2`, `WHIM-END\n` at `len - 16` (all only if they fit).
4. `on_disk_bytes`: Windows `GetCompressedFileSizeW` (wide path, combine high/low DWORD; `INVALID_FILE_SIZE` + `GetLastError() != 0` = error); Unix `std::os::unix::fs::MetadataExt::blocks() * 512`.
5. `run` prints `apparent_bytes=<n>` and `on_disk_bytes=<n>`, and exits 1 with `error: filesystem did not create a sparse file` if on-disk > 100_000_000 (RESEARCH Pitfall 2; then the file is deleted).

Algorithm:

Use accumulated CPU deltas, not `cpu_usage()` (RESEARCH).
4. Kill every child after its sample (`child.kill()` + `wait()`).
5. Results: run 0 is reported separately as `first_run_ms` ("cold-ish", Pitfall 5); `startup_median_ms` and `startup_max_ms` over all runs; `inapp_startup_median_ms` from `startup_ms=` lines.
