If `response.clicked()` call `response.request_focus()`. On the first `show` call (`!focus_requested`) call `response.request_focus()` once so the IME test works without a click.
2. If `response.has_focus()`:
   - `let events = ui.input(|i| i.events.clone());` for each `egui::Event::Ime(ev)` call `self.ime.apply(&ev)`.
   - If `!self.ime.is_composing()` and `ui.input(|i| i.key_pressed(egui::Key::Escape))` call `self.ime.escape()`.
   - Skip arrow/Page/Home/End scroll keys while `self.ime.is_composing()` (keys belong to the IME during composition).
   - Probe caret (UI-SPEC: fixed probe caret at the top-left text cell is acceptable): `caret_origin = pos2(snap(text_rect.left() + 16.0), snap(text_rect.top()))`. When `is_composing()` or `!committed().is_empty()`, paint a 40pt-high SECONDARY overlay strip across the text rect's top (rows 0-1); row 0 = preedit text in TEXT with a 1pt ACCENT underline under its galley width (`painter.line_segment` at baseline y = row bottom - 3); row 1 = committed probe text in TEXT. Caret = 2pt-wide, 20pt-high ACCENT rect at `caret_origin.x + preedit_galley.size().x`, drawn static (no blink timer, UI-SPEC/RESEARCH Pattern 5) whenever focused.

3. When not focused, do not touch `o.ime` (stays None so IME is disabled, Pitfall 7).
