2. `src/source.rs` (the D-02 contract; implement fully):
```rust
//! Read-only content access (D-01, D-02). FileSource implements it now; the Phase 3 piece table later.
#[derive(Debug)]
pub enum SourceError { Changed, Io(std::io::Error) }
impl SourceError { pub fn is_changed(&self) -> bool }
impl std::fmt::Display for SourceError   // Changed => "file changed on disk", Io(e) => e.to_string()
impl std::error::Error for SourceError {}
pub trait TextSource: Send + Sync {
    fn len(&self) -> u64;
    fn is_empty(&self) -> bool { self.len() == 0 }
    /// Bumped on every content change. FileSource returns 0 (read-only, Pitfall 11).
    fn version(&self) -> u64;
    /// Fill all of `buf` with bytes [start, start + buf.len()). Err(Changed) if the range is
    /// not inside len() (checked_add; never panics) or the underlying data changed.
    fn read_range(&self, start: u64, buf: &mut [u8]) -> Result<(), SourceError>;
}
/// Reads min(max, len - start) bytes at `start` (empty Vec if start >= len).
pub fn read_clamped(src: &dyn TextSource, start: u64, max: usize) -> Result<Vec<u8>, SourceError>;
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum EolKind { Lf, Crlf, Mixed, Unknown }
impl EolKind { pub fn label(self) -> &'static str }   // "LF", "CRLF", "Mixed", Unknown => "LF"
/// In-memory source for tests and small buffers; counts bytes read so tests can assert
/// that algorithms never read whole files (CORE-02).
pub struct MemSource { data: Vec<u8>, read_bytes: std::sync::atomic::AtomicU64 }
impl MemSource { pub fn new(data: Vec<u8>) -> Self; pub fn bytes_read(&self) -> u64; pub fn reset_counter(&self) }
impl TextSource for MemSource   // version() = 0
```
Colocated tests `source::tests`: read inside/at end/past end (past end => `Err(Changed)`, offset `u64::MAX - 1` with len 4 => `Err(Changed)`, no panic), `read_clamped` clamps, counter counts.

```rust
pub const MISSING_GLYPHS_NOTICE: &str = "Some characters can't be shown: no installed font has them";
#[derive(Debug, PartialEq, Eq)] pub enum FontAction { Nothing, Install, NoticeMissing }
pub struct FontFallback { state: State }   // enum State { NotInstalled, Installed { checks: u8 }, Done }
impl FontFallback {
    pub fn new() -> Self;
    /// Pure state machine (unit-tested with a mock predicate).
    pub fn decide(&mut self, text: &str, has_glyph: impl FnMut(char) -> bool) -> FontAction;
    /// Call when a newly decoded visible paragraph is laid out. Fast path: `text.is_ascii()` => None
    /// without touching fonts. On Install: `ctx.add_font_provider(Arc::new(egui_system_font_provider::SystemFontProvider::new()))`
    /// then `ctx.request_repaint()` once. Returns Some(MISSING_GLYPHS_NOTICE) exactly once per session.
    pub fn check(&mut self, ctx: &egui::Context, font_id: &egui::FontId, text: &str) -> Option<&'static str>;
}
```
`decide` rules: `Done` => Nothing. Text ASCII => Nothing. `NotInstalled`: if any non-ASCII char has `!has_glyph(c)` => state `Installed{checks:0}`, return Install; else Nothing. `Installed{checks}`: if a non-ASCII char is still missing, increment `checks`; when `checks` reaches 3 => state `Done`, return NoticeMissing; else Nothing. If nothing missing while Installed => state `Done`, Nothing. In `check`, the predicate is `|c| ctx.fonts_mut(|f| f.has_glyph(font_id, c))`. Never call `add_font_provider` more than once (provider fonts cannot be unloaded; enumeration thread must not start for ASCII files, keeping startup/idle footprint at Phase 1 levels). Write the `fonts::tests` per <behavior> first (RED), then implement.
