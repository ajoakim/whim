```rust
pub const CACHE_BLOCK: usize = 65_536;
pub const CACHE_BLOCKS: usize = 16;            // 1 MiB total
pub const DIRECT_READ_MIN: usize = 256 * 1024; // larger requests bypass the cache (workers)
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct FileIdentity { pub len: u64, pub modified: Option<std::time::SystemTime> }
pub struct FileSource { path: PathBuf, file: File, identity: FileIdentity, cache: Mutex<ChunkCache> }
impl FileSource {
    pub fn open(path: &Path) -> Result<Self, SourceError>;           // File::open + metadata -> identity
    pub fn reopen(&self) -> Result<Self, SourceError>;               // NEW handle by path (never try_clone: shares cursor on Windows); identity must equal self.identity else Changed
    pub fn reopen_for_scan(&self) -> Result<Self, SourceError>;      // as reopen; on Windows add OpenOptionsExt::custom_flags(0x0800_0000 /* FILE_FLAG_SEQUENTIAL_SCAN */)
    pub fn path(&self) -> &Path;
    pub fn identity(&self) -> FileIdentity;
    #[cfg(test)] pub fn cached_blocks(&self) -> usize;
}
impl TextSource for FileSource { /* len = identity.len, version = 0 */ }
pub fn read_full_at(f: &File, buf: &mut [u8], off: u64) -> Result<(), SourceError>;
```
- OS split exactly as RESEARCH Pattern 1: `#[cfg(unix)] std::os::unix::fs::FileExt::read_at`, `#[cfg(windows)] std::os::windows::fs::FileExt::seek_read`. `read_full_at` loops on short reads, `Ok(0)` => `Err(Changed)`, retries `Interrupted`, other errors => `Err(Io(e))`.
- `read_range(start, buf)`: `start.checked_add(buf.len() as u64)` must be `<= identity.len` else `Err(Changed)`. Empty buf => Ok. If `buf.len() >= DIRECT_READ_MIN`: `check_identity()` then `read_full_at` directly. Else copy from cache blocks `start / CACHE_BLOCK ..= (end-1) / CACHE_BLOCK`; on a miss: `check_identity()` (`self.file.metadata()` len and modified must equal identity, else Changed), read `min(CACHE_BLOCK, len - idx*CACHE_BLOCK)` bytes into a `Box<[u8]>`, insert, evicting the least-recently-used entry when 16 are cached (monotonic `tick` counter per access).
- `ChunkCache` is private: `Vec<Entry { idx: u64, data: Box<[u8]>, last_use: u64 }>` plus `tick: u64`. Mutex lock via `lock().unwrap_or_else(|e| e.into_inner())` (no panic on poison).
- No `unwrap`/`expect`/unchecked slice indexing on file-derived values outside tests (release has `panic = "abort"`); use `u64` math and `usize::try_from` with `Changed` on failure.
- No memmap2 use in this file.
Write tests per <behavior> first using `testutil::TempDir` (truncate/append through a second `OpenOptions::new().write(true)` handle while the FileSource is open; works on Windows because std opens with FILE_SHARE_READ|WRITE|DELETE).

```rust
pub const HEAD_BYTES: usize = 65_536;
pub const SNIFF_BYTES: usize = 8_192;
#[derive(Debug)]
pub enum OpenError { NotRegular { name: String }, Io { name: String, reason: String } }
impl OpenError {
    pub fn message(&self) -> String;       // NotRegular: "Couldn't open {name}: it is not a regular file (folder, pipe or device)."
                                           // Io: "Couldn't open {name}: {reason}. Check that the file exists and you have permission to read it."
    pub fn short_message(&self) -> String; // NotRegular: "Can't open {name}: not a regular file"; Io: same as message()
    pub fn name(&self) -> &str;
}
pub fn display_name(path: &Path) -> String;  // file_name lossy, else path.display()
pub struct Opened { pub source: FileSource, pub path: PathBuf, pub name: String, pub len: u64, pub head: Vec<u8>, pub binary: bool, pub utf16_bom: bool, pub eol: EolKind }
pub fn classify(path: &Path) -> Result<u64, OpenError>;   // std::fs::metadata (follows symlinks; stat never blocks on a FIFO); !file_type().is_file() => NotRegular; Ok(len)
pub fn open_blocking(path: &Path) -> Result<Opened, OpenError>; // classify, FileSource::open, read_clamped(head, 0, HEAD_BYTES), heuristics
pub fn looks_binary(sample: &[u8]) -> bool;   // over sample[..min(len, SNIFF_BYTES)]
pub fn has_utf16_bom(sample: &[u8]) -> bool;
pub fn eol_of_sample(sample: &[u8]) -> EolKind;
pub type OpenResult = (u64, PathBuf, Result<Opened, OpenError>);
pub fn spawn_open(gen: u64, path: PathBuf, notify: Box<dyn Fn() + Send>) -> std::sync::mpsc::Receiver<OpenResult>;
```
- `looks_binary`: `contains(&0)` OR `control * 100 > 30 * n` where control = byte `< 0x20` except `\t`, `\n`, `\r`, `0x0C`, `0x1B`, plus `0x7F`; `n == 0` => false.
- `eol_of_sample`: count `\n` (memchr) and `\r\n` pairs; 0 newlines => Unknown; all CRLF => Crlf; none CRLF => Lf; else Mixed.
- `spawn_open`: `std::thread::spawn` running `open_blocking`, sends `(gen, path, result)`, then calls `notify()` (the app passes `ctx.request_repaint`). A send error (receiver dropped because a newer open superseded it) is ignored. The UI thread never calls `File::open` or `metadata` on user paths (D-19); a worker stuck on a slow path is simply abandoned via its generation id.
- Windows reserved names (`NUL`, `CON`) fail `metadata` or report non-file: both map to an OpenError (no special case needed; add a `#[cfg(windows)]` test that `classify(Path::new("NUL"))` is Err).
- Never read more than `HEAD_BYTES` here (CORE-01: first page needs only the first block).
Write the tests per <behavior> first; FIFO test uses `std::process::Command::new("mkfifo")` and is `#[cfg(unix)]`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem -> FileSource | Untrusted file bytes, length and identity; another process may truncate/replace the file at any time |
| user path (CLI/dialog/drop) -> open | Path may name a directory, FIFO, device, symlink or reserved name |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-09 | T/D | src/filesource.rs read_range | mitigate | Positional reads only (no mmap => no SIGBUS/UB); short read or len/mtime mismatch => `SourceError::Changed`; checked u64 arithmetic; no unwrap on file-derived data (panic=abort) |
| T-02-10 | D | src/open.rs classify | mitigate | `metadata().is_file()` before `File::open` rejects FIFO/device/dir; open runs on a worker thread; stale workers ignored via generation id |
| T-02-11 | D | memory exhaustion via huge file | mitigate | Cache capped at 16 x 64 KiB; head sample capped at 64 KiB; no whole-file read APIs (`grep` gate) |
| T-02-12 | T | symlink to device/FIFO | mitigate | `std::fs::metadata` follows symlinks, so the target type is classified and rejected |
| T-02-13 | I | error messages | accept | Messages show the file name and OS reason only to the local user who chose the path |
| T-02-14 | T | Windows shared handles | mitigate | One handle per thread via `reopen` by path (never `try_clone`), identity verified on reopen |
