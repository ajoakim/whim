```rust
pub const BLOCK: u64 = 65_536;
pub const INDEX_READ: usize = 4 * 1024 * 1024;
pub const BATCH_INTERVAL: std::time::Duration = std::time::Duration::from_millis(100);
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum Exactness { Exact, Estimated }
pub enum IndexMsg {
    Batch { gen: u64, cum_tail: Vec<u64>, covered: u64 },   // cumulative counts for newly completed full blocks
    Done { gen: u64, total_newlines: u64, cr_total: u64 },
    Failed { gen: u64, error: String },
    Cancelled { gen: u64 },
}
impl IndexMsg { pub fn gen(&self) -> u64 }
pub struct LineIndex { len: u64, cum: Vec<u64>, covered: u64, complete: bool, cancelled: bool, total_newlines: u64, cr_total: u64, head_avg: Option<f64> }
impl LineIndex {
    pub fn new(len: u64, head: &[u8]) -> Self;        // cum = vec![0]; head_avg = head.len()/newlines(head) if newlines > 0
    pub fn apply(&mut self, msg: &IndexMsg);          // gen filtering is the caller's job
    pub fn mark_cancelled(&mut self);
    pub fn is_complete(&self) -> bool; pub fn is_cancelled(&self) -> bool;
    pub fn covered(&self) -> u64; pub fn len(&self) -> u64;
    pub fn progress_pct(&self) -> u8;                 // covered * 100 / len via u128; 100 when complete or len == 0
    pub fn avg_line_bytes(&self) -> Option<f64>;      // covered / cum.last() if cum.last() > 0, else head_avg
    pub fn line_of(&self, src: &dyn TextSource, off: u64) -> Result<(u64, Exactness), SourceError>;    // 0-based line
    pub fn offset_of(&self, src: &dyn TextSource, line0: u64) -> Result<(u64, Exactness), SourceError>;
    pub fn total_lines(&self) -> (u64, Exactness);    // complete: total_newlines + 1; else estimate max(cum.last()+1, len/avg + 1)
    pub fn eol(&self) -> Option<EolKind>;             // Some only when complete: cr_total == 0 => Lf; cr_total == total_newlines => Crlf; else Mixed; no newlines => Unknown
}
pub struct IndexJob { pub gen: u64, pub cancel: std::sync::Arc<std::sync::atomic::AtomicBool>, pub rx: std::sync::mpsc::Receiver<IndexMsg>, handle: Option<std::thread::JoinHandle<()>> }
impl IndexJob { pub fn cancel(&self); pub fn is_finished(&self) -> bool; }
impl Drop for IndexJob { fn drop(&mut self) { self.cancel(); } }   // cancel only; must not block the UI thread
pub fn spawn_indexer(gen: u64, src: Box<dyn TextSource>, notify: Box<dyn Fn() + Send>) -> IndexJob;
```
Invariants: `cum[i]` = newlines in `[0, i*BLOCK)` for every completed full block; `covered = (cum.len()-1) * BLOCK` until Done, then `covered = len`. Mapping (RESEARCH Pattern 2): `line_of(off)`: `b = min(off / BLOCK, cum.len()-1)`; if `off <= covered` => `cum[b] + memchr count of '\n' in [b*BLOCK, off)` (read via `read_clamped`, at most 64 KiB) => Exact. Else Estimated: `avg = avg_line_bytes()`; None => `cum.last()`; Some(a) => `cum.last() + ((off - covered) as f64 / a) as u64`. `offset_of(0) = 0`. If `line0 <= cum.last()` (or complete and `line0 <= total_newlines`): find block `b` with `cum[b] < line0 <= cum[b+1]` (for the tail past the last checkpoint when complete, scan from the last checkpoint; tail < 64 KiB), scan with `memchr_iter(..).nth((line0 - cum[b] - 1) as usize)` => offset = pos + 1, Exact. Complete and `line0 > total_newlines` => offset of the last line, Exact. Otherwise Estimated: `covered + (line0 - cum.last()) * avg` clamped to `len.saturating_sub(1)` (f64 math, then `min`; Pitfall 10: never f32).
Worker: own thread; reusable `vec![0u8; INDEX_READ]`; loop reads `min(INDEX_READ, len - pos)` with `src.read_range`; for each full 64 KiB sub-slice push the cumulative count (`memchr::memchr_iter(b'\n', blk).count()`), add `memchr::memchr_iter(b'\r', blk).count()` to `cr_total`; tail bytes (< 64 KiB at EOF) count only into `total_newlines`/`cr_total`. Check `cancel.load(Ordering::Relaxed)` before each read => send `Cancelled`, notify, return. Send `Batch` only when `last_sent.elapsed() >= BATCH_INTERVAL` and there are new entries; call `notify()` only after a successful send. At end send `Done` then `notify()`. Read error => `Failed { error: e.to_string() }` + notify. A failed `send` (receiver dropped) => return silently. No `unwrap`/`expect` in the worker (panic = abort). After Done/Cancelled/Failed the thread exits: zero idle CPU (Pitfall 7).
Write the tests per <behavior> first. The worker tests drain `rx` with `recv_timeout`.
