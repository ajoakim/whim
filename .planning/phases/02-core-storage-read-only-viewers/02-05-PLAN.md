Implement in `src/scroll.rs` (pure, no egui):
```rust
pub const CAP: u64 = 10_000;
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct Segment { pub start: u64, pub end: u64, pub newline_end: bool, pub hard_continuation: bool }
pub fn next_boundary(src: &dyn TextSource, s: u64) -> Result<u64, SourceError>;      // s < len => (s, len]; s >= len => len
pub fn segment_start(src: &dyn TextSource, a: u64) -> Result<u64, SourceError>;      // largest boundary <= min(a, len)
pub fn prev_segment_start(src: &dyn TextSource, start: u64) -> Result<Option<u64>, SourceError>; // None at 0, else segment_start(start-1)
pub fn segment_at(src: &dyn TextSource, start: u64) -> Result<Segment, SourceError>;
pub fn last_segment_start(src: &dyn TextSource) -> Result<u64, SourceError>;         // len == 0 => 0 else segment_start(len-1)
pub(crate) fn next_boundary_cap(src: &dyn TextSource, s: u64, cap: u64) -> Result<u64, SourceError>;
pub(crate) fn segment_start_cap(src: &dyn TextSource, a: u64, cap: u64) -> Result<u64, SourceError>;
```
Boundary set (RESEARCH Pattern 3): `{0, len} ∪ {n+1 : data[n] == b'\n'} ∪ {adj(p) : p % cap == 0, 0 < p < len, no b'\n' in [p-cap, p)}` where `adj(p)` advances past at most 3 UTF-8 continuation bytes (0x80..=0xBF), capped at len. Forward step: `m` = first `\n` at or after `s` searched only within `[s, s + 2*cap + 4)`; for each aligned `q` in `(s, min(m+1, s+2*cap+4)]` with `q % cap == 0`, test the newline-free window `[q-cap, q)` (one memchr over a bounded read); the first hit `adj(q)` that is `> s` wins; else `m+1` or `min(len, ...)`. Backward step for `a`: look back `3*cap` bytes for the last `\n` => `n1`; candidate `p = (a / cap) * cap`, and walk candidates `p, p - cap, ...` while `p >= n1 + cap` and `p > 0`: return the first `adj(p)` that is `<= a` (handles `a` inside the continuation bytes right after `p`, the edge case not covered by the research formula); otherwise return `n1`. The public functions call the `_cap` versions with `CAP`. All reads go through `read_clamped` in windows of at most `3*cap + 8` bytes; checked/saturating u64 math only (no f32).
Pitfall 5: a hard break can fall between `\r` and `\n`; that is allowed; `text::decode_segment` drops a lone trailing `\r` only when the next byte is `\n` (Task 2 handles display). Write the property tests per <behavior> first (RED), then implement (GREEN).
