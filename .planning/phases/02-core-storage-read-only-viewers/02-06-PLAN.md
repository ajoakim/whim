```rust
#[derive(Clone, Copy, Debug, Default, PartialEq, Eq)]
pub struct Selection { pub anchor: u64, pub head: u64 }
impl Selection {
    pub fn caret(off: u64) -> Self;
    pub fn range(&self) -> std::ops::Range<u64>;   // min..max
    pub fn len(&self) -> u64; pub fn is_empty(&self) -> bool;
    pub fn extend_to(&mut self, off: u64);         // head = off
    pub fn select_all(len: u64) -> Self;           // anchor 0, head len
    pub fn clamp(&mut self, len: u64);
}
pub const WORD_SCAN: u64 = 256;
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum CharClass { Word, Space, Other }
pub fn class_of(c: char) -> CharClass;   // alphanumeric or '_' => Word; whitespace => Space; else Other
pub fn word_bounds(src: &dyn TextSource, off: u64) -> Result<std::ops::Range<u64>, SourceError>;
```
`word_bounds`: read the window `[off.saturating_sub(256), min(len, off+256))` once with `read_clamped`; move the window start forward past continuation bytes (0x80..=0xBF) so decoding starts on a char boundary; decode with `utf8_chunks` (invalid bytes are class Other, one byte each); pick the char containing `off` (or the char before when `off == len`); expand left/right while the class matches, stopping at the window edges; return absolute byte offsets. Write the tests per <behavior> first.

Implement in `src/copy.rs`:
```rust
pub const COPY_IMMEDIATE_MAX: u64 = 16 * 1024 * 1024;   // output text bytes
pub const COPY_HARD_CAP: u64 = 256 * 1024 * 1024;       // output text bytes (Q4: hex cap applies to produced text)
pub const COPY_STEP: usize = 1024 * 1024;
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum CopyKind { Text, Hex }
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum CopyTier { Immediate, Confirm, OverCap }
pub fn output_size(kind: CopyKind, bytes: u64) -> u64;
pub fn tier(kind: CopyKind, bytes: u64) -> CopyTier;
pub fn max_bytes_for(kind: CopyKind) -> u64;
pub fn hex_text(bytes: &[u8], leading_space: bool, out: &mut String);   // uppercase pairs, single spaces
pub enum CopyMsg { Progress { gen: u64, done: u64, total: u64 }, Done { gen: u64, text: String }, Failed { gen: u64, error: String }, Cancelled { gen: u64 } }
impl CopyMsg { pub fn gen(&self) -> u64 }
pub struct CopyJob { pub gen: u64, pub cancel: Arc<AtomicBool>, pub rx: Receiver<CopyMsg>, pub started: std::time::Instant, handle: Option<JoinHandle<()>> }
impl CopyJob { pub fn cancel(&self); }
impl Drop for CopyJob { fn drop(&mut self) { self.cancel(); } }   // cancel only; must not block the UI thread
pub fn spawn_copy(gen: u64, src: Box<dyn TextSource>, range: std::ops::Range<u64>, kind: CopyKind, notify: Box<dyn Fn() + Send>) -> CopyJob;
```
Worker: refuse (Failed "selection exceeds the copy limit") if `tier == OverCap` (defence in depth; the UI never starts it). Text: one `Vec<u8>` with capacity `range` length (known, <= 256 MiB), read in `COPY_STEP` chunks, check `cancel` before each chunk, then `String::from_utf8(v).unwrap_or_else(|e| String::from_utf8_lossy(e.as_bytes()).into_owned())` (zero-copy when valid). Hex: `String::with_capacity(output_size)` and `hex_text` per chunk. Progress at most every 100 ms; `notify()` after each sent message; Done/Failed/Cancelled followed by `notify()`. Never `unwrap` I/O; `usize::try_from` for capacities with Failed on overflow. The UI thread calls `ctx.copy_text(text)` on Done (02-11); this module never touches egui.
Write the tests per <behavior> first (zero source = test-local struct implementing TextSource returning zeros).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user selection -> clipboard | Selection may span the whole multi-GB file |
| file bytes -> clipboard text | Untrusted bytes (invalid UTF-8) become clipboard text |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-24 | D | src/copy.rs memory | mitigate | Hard cap 256 MiB of output text (hex ~85 MiB of bytes), confirm above 16 MiB, worker refuses OverCap; buffers pre-sized from the known range |
| T-02-25 | D | copy worker lifecycle | mitigate | Cancellable per 1 MiB step via AtomicBool; Drop cancels; throttled progress; send failure exits |
| T-02-26 | T | invalid UTF-8 to clipboard | mitigate | Lossy conversion (U+FFFD) only for clipboard text; no panics on invalid data |
| T-02-27 | D | src/selection.rs word scan | mitigate | Bounded 256-byte window each side; never reads a whole line |
