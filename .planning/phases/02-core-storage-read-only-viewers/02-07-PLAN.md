```rust
/// One visual row inside a decoded segment: char range [first_char, first_char + chars).
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub(crate) struct RowSpan { pub first_char: usize, pub chars: usize }
pub(crate) trait RowLayouter { fn rows(&mut self, seg: &Segment, decoded: &Decoded) -> Vec<RowSpan>; }   // at least one row (empty segment => one empty row)
#[cfg(test)] pub(crate) struct MonoLayouter { pub wrap_at: Option<usize> }
pub(crate) fn row_start_of(src: &dyn TextSource, lay: &mut dyn RowLayouter, off: u64) -> Result<u64, SourceError>;
pub(crate) fn step_rows(src: &dyn TextSource, lay: &mut dyn RowLayouter, anchor: u64, delta: i64) -> Result<u64, SourceError>;
pub(crate) fn anchor_for_end(src: &dyn TextSource, lay: &mut dyn RowLayouter, visible_rows: usize) -> Result<u64, SourceError>;
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub(crate) enum GutterMark { Number(u64, Exactness), Continuation, Blank }
pub(crate) fn gutter_cells(prev: usize, total: (u64, Exactness)) -> usize; // max(prev, digits(total).max(4) + (1 if Estimated))
```
Row byte = `seg.start + decoded.byte_of_char[row.first_char]`. Stepping: inside a segment move between RowSpans; past the last row go to `segment_at(seg.end)` (if `seg.end < len`); before the first row go to `prev_segment_start(seg.start)` and its last row. Because segment boundaries are stateless (02-05) and rows inside a segment depend only on (segment, width, wrap), stepping is an exact inverse. `anchor_for_end`: last row of `last_segment_start` then `step_rows(.., -(visible_rows-1))`. Segment decode: `read_clamped(src, seg.start, (seg.end - seg.start) as usize)` + next byte check for `next_is_newline` (one extra byte read) + `decode_segment`. Gutter numbering: first row of a segment gets `Number` if the segment starts at 0 or after a `\n` (i.e. `!seg.hard_continuation`), `Continuation` if `seg.hard_continuation`, other rows `Blank`; the number of the first visible segment comes from `index.line_of(src, seg.start)` (+1 for 1-based), then +1 per subsequent segment whose predecessor had `newline_end`; exactness per row = Exact if `seg.start <= index.covered()` or index complete, else Estimated (UI-SPEC: rows inside the indexed prefix are exact). Write the tests per <behavior> first with `MonoLayouter`.
