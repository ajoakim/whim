```rust
pub struct HexView { anchor: u64, sub_px: f32, hscroll_px: f32, max_row_w: f32, scroll_epoch: u64 }
impl HexView {
    pub fn new() -> Self;
    pub fn reset(&mut self);
    pub fn top(&self) -> u64;
    pub fn set_top_from_text(&mut self, text_top: u64); // anchor = (text_top / 16) * 16 clamped; D-09 switch
    pub fn top_to_text(&self) -> u64; // segment_start(anchor) when entering text view
    pub fn jump_to(&mut self, off: u64) -> u64; // anchor = align(off); returns snapped offset for display
    pub fn scroll_epoch(&self) -> u64;
    pub fn show(&mut self, ui: &mut egui::Ui, source: &dyn TextSource, sel: &mut Selection) -> egui::Response;
}
```
HexView does not own `Selection`; it's `&mut Selection` per show call, shared with the text view from the document state (02-10). Cell geometry: `cell_w = ui.fonts_mut(|f| f.glyph_width(&font, '0'))` where font = `FontId::monospace(theme::MONO_SIZE)`. Hex row width computed once per frame; `max_row_w` grows monotonically per file; hscroll clamp `max(0.0, max_row_w - content_w)`. Hit test only via monospace cell arithmetic — never `Galley::cursor_from_pos`. ASCII cell = `floor((x - ascii_x0) / cell_w)`; byte = `row_start + cell`; clamp to row bounds. Paint offset column 16 uppercase hex digits `MUTED`; bytes `XX` separated by 1 cell inside groups of 8, groups separated by 24 pt; ASCII column 16 cells printable TEXT / `·` MUTED_DIM; `SEPARATOR` vertical line at ASCII left edge; per-row selection rect over digits + half gaps each side mirrored on ASCII cells; unfocused uses `SELECTION_INACTIVE`. Rows painted from `anchor & !15` in steps of 16 while y < bottom; read `16 * (visible_rows + 1)` bytes per frame through `read_clamped`. Scrollbar exact proportional: `thumb(anchor/len as f64, visible_bytes/len as f64)`; drag maps `frac * len` then align down to 16. No f32 for offsets (Pitfall 10). Empty file: centered `MUTED` "This file is empty.".
