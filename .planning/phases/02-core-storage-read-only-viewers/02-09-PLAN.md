In `src/view/textview.rs`, add after the layout-guts (but before the `scrollbar` geometry fns) the following interaction fns. The `show` fn already owns `sel: &mut Selection` and a `scroll_epoch: u64`:

```rust
/// Increment scroll_epoch once per user-initiated movement (keyboard/page/scrollbar drag).
/// Call from show before any movement handling so 02-11 can detect post-jump scrolling.
pub(crate) fn increment_scroll_epoch(&mut self) { self.scroll_epoch = self.scroll_epoch.wrapping_add(1); }
/// Mouse click / press at x inside the content. Returns the byte of the char nearest x.
/// If inside a segment start, call segment_at to find the segment then decode_segment to get
/// byte_of_char maps; the nearest char via byte_of_char gives the click byte offset.
pub(crate) fn handle_click(&mut self, cx: &TextViewCtx<'_>, x: f32) -> u64;
/// Select a word starting at `off`: read the 256-byte window around off in the cache,
/// call selection::word_bounds, return the absolute byte range of the clicked word.
pub(crate) fn handle_word_select(&mut self, off: u64) -> std::ops::Range<u64>;
/// Triple-click the paragraph containing byte off: compute seg.start = segment_start(off),
/// then paragraph is [seg.start, next_boundary_from(seg.start)). Return absolute byte range.
pub(crate) fn handle_triple_select(&mut self, off: u64) -> std::ops::Range<u64>;
/// Caret position given byte off: read the segment containing off, return the galley cursor
/// index via decoded.byte_of_char. Implemented in 02-07's focus handling.
```
Rules: all reads go through read_clamped in windows bounded by CAP and 3*CAP (02-05); word_bounds from 02-06 selects the maximal alphanumeric-or-underscore run; triple-click selects from segment_start; gutter numbers (02-06) use segment_start and segment_at; click beyond the last visible row triggers select_all(len) silently; mouse events that change Selection increment scroll_epoch; never panic, all u64 clamping uses checked_*/saturating_*.
Write the tests per <behavior> first (headless egui smoke, no visual output needed); tests of mouse click + word/triple select + caret byte return.
